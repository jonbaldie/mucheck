relevantOps :: (Data a, Eq a) => a -> [(MuVar, MuOp)] -> [(MuVar, MuOp)] #

Filter out identity ops (where source == target). The applicability check (traversal) is deferred to once in mutate, which returns an empty list for ops that do not match any AST node. This removes the duplicate AST traversal that the old relevance-probe pass performed.
